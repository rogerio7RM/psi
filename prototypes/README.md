# PrimeSphere — Social Cards V1

Protótipo visual **offline** de oito cards 4:5 para Instagram/Facebook, com estilo azul-escuro, variações positivas em verde e negativas em vermelho.

## Como visualizar

Abra `social-cards-v1.html` no navegador local. Para baixar pelo GitHub, abra o arquivo, clique em **Raw** e salve como `.html`; então abra com Chrome/Edge. Use zoom 100% e ajuste o tamanho da janela para inspecionar o layout.
